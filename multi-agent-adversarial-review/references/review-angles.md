# 推荐审查视角

根据变更适配此列表；主 agent 为每个评审 agent 分配一个视角并可新增视角。新增视角记入报告。

## 1. 正确性与回归
- 逻辑错误、边界、条件错误、相对旧行为的行为变化。
- 对调用方和既有功能的回归风险。

## 2. 并发与生命周期
- 竞态、过期回调、重入、拆除顺序、所有权转移。
- 同步与异步边界。

## 3. 错误处理与边界
- 缺失错误路径、吞错、超时/重试行为、空/零/最大输入。

## 4. 契约与兼容性
- API/模式/格式变更、破坏性变更、默认值、特性开关、跨版本兼容。

## 5. 安全与资源
- 注入、授权缺口、不安全输入处理、泄漏（内存/句柄/连接）、无界增长。

## 6. 性能与可观测性
- 热点路径、算法复杂度、新增延迟、阻塞调用、妨碍诊断的日志缺口。

## 专项视角：用户假设验证
- 用户陈述怀疑原因（"我怀疑 X"）时，将一个评审者分配到此视角。
- 任务：用证据链证实或证伪该假设。证伪也是有效产出。
- 只有此视角看到用户假设；其余视角保持中立。
